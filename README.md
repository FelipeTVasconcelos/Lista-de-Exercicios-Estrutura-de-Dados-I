**Lista-de-Exercicios-Estrutura-de-Dados-I**

  Repositório dedicado à resolução de exercícios, listas práticas e implementações desenvolvidas durante a disciplina de *Estrutura de Dados I*
  
**Objetivos**

  - Fixar conceitos fundamentais de gerenciamento de memória e estruturas de dados lineares e não-lineares.
  - Desenvolver algoritmos eficientes para manipulação, busca, ordenação e inserção de dados.
  - Aplicar boas práticas de programação na linguagem C/C++.

Exercícios resolvidos com todas as 10 questões resolvidas em C, compiladas e testadas sem erros.

Q01. Lista encadeada — carrinho de compras (inserir_item, calcular_total)

Q02. Lista sequencial — rota de entregas (remover_parada)

Q03. Fila (encadeada) — montanha-russa (enfileirar_turista, atender_turista)

Q04. Fila (vetor circular) — pedidos da cozinha (desenfileirar_pedido). 

Q05. Pilha (vetor) — caixas no palete (empilhar_caixa, desempilhar_caixa)

Q06. Pilha (encadeada) — undo de preços (empilhar_alteracao, desfazer_alteracao)

Q07. Bubble Sort — 8 preços de pacotes turísticos

Q08. Insertion Sort — 10 horários de fornecedores

Q09. Busca linear — 15 códigos de barras

Q10. Busca binária — 1000 IDs de clientes ordenados
